# Glossary & Terminology

This glossary maps the internal technical terminology used in the database schema to the clean, project-oriented terms presented to the users.

| Database / Code Term | Customer-Facing UI Term | Category | Description |
| :--- | :--- | :--- | :--- |
| `Booking` | **Project Request** | Transaction | A direct, private request sent by a customer to a selected professional. |
| `Requirement` | **Lead / Project Requirement** | Marketplace | A public requirement posted by a customer on the open board for matchmaking. |
| `Provider` | **Trade Professional / Consultant** | Role | Standard supplier role. Encompasses manual builders and consultants. |
| `Quotation` | **Proposal / Quote** | Document | A milestone-based cost proposal submitted by a professional. |
| `Project` | **Active Project** | Execution | An approved contract in progress, divided into milestones and phases. |
| `ConsultationBooking` | **Consultation Schedule** | Event | A scheduled video/in-person advisory call with an architect or engineer. |
