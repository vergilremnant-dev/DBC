# Feature Catalog

This catalog outlines key features currently implemented in the DesignBuildConnect codebase.

## 1. Authentication & Security
* **In-Place Login/Register:** Form switching on the authentication card without URL route changes.
* **Registration Verification UI:** Standardized 6-digit numeric input with a 30-second resend cooldown timer and secure destination masking (email/phone).

## 2. Service Directory & Discovery
* **Dynamic search:** Full-text search filters for categories, experience, city location, and cost ratings.
* **Trust Strip:** Layout detailing verified profiles and direct quote exchanges.

## 3. Interactive Inbox
* **Direct Messaging:** Multi-role conversational inbox with read receipts, message history, and desktop/mobile navigation links pointing to `/workspace/inbox`.
