# Product Requirements Document (PRD)

This document contains core requirements for the DBC project matching ecosystem.

## Core Focus: Request ➔ Quotation ➔ Project Lifecycle

1. **Direct Professional Hiring:**
    * Customers must be able to explore verified professional profiles by trade (Plumbing, Electrical, Carpentry, Painting, etc.) or consultancy (Architect, Civil Engineer, Vastu Consultant).
    * Customers can submit a private Project Request containing preferred dates and estimated budgets.

2. **Marketplace Leads Bidding:**
    * Customers can submit general construction requirements (leads) to the public board.
    * Matching professionals can submit a multi-milestone Quotation (Proposal).

3. **Milestone-Based Execution:**
    * An approved Quotation generates an active Project.
    * Projects track progress logs, approvals, and resource allocations.
