# Phase 1: MVP Scope

The minimum viable scope focused on establishing the core marketplace pipeline:

1. **Onboarding:** In-place login/registration and verification layouts.
2. **Matching:** Private requests (`Booking`) and public bidding (`Requirement` ➔ `Quotation`).
3. **Redirection:** Customers land on the marketplace homepage, while builders/admins land directly in their workspace consoles.
4. **Messaging:** Secure communication channels for negotiation.
