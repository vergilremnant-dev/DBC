# Admin Operator Flow

Platform administrators monitor service delivery, metrics, and partner verifications.

## Workflow Actions
* **Categories Manager:** Add/edit service icons, edit descriptions, and set display order.
* **Verification Manager:** Review provider profiles, verify licenses, and toggle verification badges.
* **Reviews Management:** Hide reported reviews or restore them to the public catalog.
* **Analytics Overview:** Monitor user growth, active subscriptions, and payment statuses.
