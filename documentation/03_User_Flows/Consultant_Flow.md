# Consultant Workspace Flow

Architects and engineers manage advisory calls and structural review sessions.

## Workflow Sequence
1. **Profile Setup:** Define specialization area, consultation fees, and weekly calendar slots.
2. **Booking Request:** Customers book consultation schedules.
3. **CRM Coordination:** Consultant reviews booking info, accepts/declines, or reschedules when conflicting dates occur.
4. **Execution:** Deliver design blueprints and upload consultation report worksheets.
