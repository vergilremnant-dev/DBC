# Screen Inventory & Page Directory

This list inventories all front-facing pages implemented inside `src/pages/`.

*   **Public Portal:**
    *   `PublicMarketplace.tsx` (`/`) - Hero search, timeline, and categories checklist.
    *   `CategoryProvidersPage.tsx` (`/category/:slug`) - Filterable directory of builders.
    *   `SearchResultsPage.tsx` (`/search`) - Dynamic search results listing.
    *   `SubscriptionsPage.tsx` (`/subscriptions`) - Razorpay pricing table.
    *   `KnowMorePage.tsx` (`/know-more`) - About page.
    *   `RequestCallbackPage.tsx` (`/request-callback`) - Public advisory callback form.
*   **Authentication:**
    *   `LoginPage.tsx` (`/login`) - In-place login, signup, verification wizard.
*   **Customer Workspace:**
    *   `WorkspaceOverview.tsx` (`/workspace/overview`) - KPI summary cards.
    *   `WorkspaceBookings.tsx` (`/workspace/bookings`) - Private request tracking lists.
*   **Professional Workspace:**
    *   `TradeProfessionalDashboard.tsx` (`/workspace/dashboard`) - Opportunities metrics.
    *   `RequirementMarketplace.tsx` (`/workspace/leads`) - Bidding directory.
    *   `QuotationManagementPage.tsx` (`/workspace/quotations`) - Cost estimations sheet.
*   **Consultant Workspace:**
    *   `ConsultantDashboard.tsx` - Schedule allocations.
*   **Admin Console:**
    *   `AdminDashboard.tsx` (`/admin/dashboard`) - Master verification console.
