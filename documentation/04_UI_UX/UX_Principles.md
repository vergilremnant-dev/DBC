# UX Design Principles

DBC focuses on providing a professional, accessible tool for high-value construction management.

## 1. Professional Compactness
*   Maximize layout scan density by reducing font dimensions on table rows and badges.
*   Keep text labels concise (e.g. `Accept Request` instead of `Click Here to Accept This Project Request`).

## 2. Touch Target Accessibility (WCAG Compliance)
*   Ensure buttons maintain a minimum tap height of `44px` on mobile viewports for ease of use.
*   Add visible focus outlines (`outline: 2px solid #047857`) to interactive items for keyboard navigation compliance.
