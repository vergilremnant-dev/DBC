# Mobile Architecture Recommendation

For building the DesignBuildConnect mobile application, the recommended path is **React Native** (managed via **Expo**).

## Rationale
*   **Shared Coding Language:** Expo allows developers to reuse UI layouts, utility formatting functions, and Redux Toolkit slices directly from the web project.
*   **Vite to Expo Transition:** Shared TypeScript models and services can be imported directly into the mobile package.
