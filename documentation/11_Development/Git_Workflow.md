# Git Branching & Commits Workflow

DBC follows a standard git branching workflow.

## 1. Branch Naming Rules
*   `feat/feature-name` - For adding new capabilities.
*   `fix/bug-fix-name` - For resolving errors.
*   `docs/doc-updates` - For updating markdown or documentation files.

## 2. Commit Message Formats
Follow the Conventional Commits specification:
*   `feat(auth): add OTP verification timers`
*   `fix(sw): handle failed fetches to resolve TypeErrors`
*   `docs: create centralized documentation portal`
