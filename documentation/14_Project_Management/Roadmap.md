# Project Feature Roadmap

This roadmap outlines completed features and future development phases.

## Phase 1: MVP Core Pipeline (Completed)
*   Customer/Provider registration toggles and verification layouts.
*   Direct private requests and public marketplace leads.
*   Multi-milestone quotations and active project generation.
*   Direct messaging and Razorpay subscription pass billing.

## Phase 2: Escrow Payouts & Mobile Launch (Planned)
*   Escrow-backed milestone releases.
*   Native mobile application using React Native / Expo.
*   Twilio OTP sms logins and push notifications.
